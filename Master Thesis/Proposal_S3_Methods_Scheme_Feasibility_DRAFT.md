## Research methods

The predictor is a residual mixture of experts following Ye and Borde [5]: a base network trained on firm characteristics and then frozen, a small number of expert networks learning corrections to its forecast, and a gate supplying the weights with which those corrections are combined. The experts see only firm characteristics, so regime information reaches the prediction solely through the gate. They are multilayer perceptrons, plain feed-forward networks, for three reasons. The input is a point-in-time characteristic vector with no time axis, and the finance literature divides cleanly on this basis, using perceptrons for characteristic panels and temporal models for sequence windows. Experts able to model temporal structure would compete with the gate for the same job, absorbing the regime-conditional variation the study sets out to measure. And the design is only computationally feasible at this scale with compact networks. Their depth and width, however, are not settled by the literature and are fixed by experiment, not by citation. What varies across the study is the source of the gate weights: classical Markov switching [1], a statistical jump model in which persistence is a tunable penalty, not a probability [18], covariate-driven transition probabilities [17], and distributional clustering by Wasserstein distance [20]. Two reference gates complete the set, one stripping out the temporal structure and one providing an interpretable floor. Each gate is fitted first and then held fixed while the mixture trains.

## Research scheme

Assemble a panel of US equities with monthly characteristics, rank-transformed following Gu, Kelly and Xiu [27], with the gate's conditioning series built separately, and establish the set of baseline models against which the mixture will later be compared. Fix the architecture through a pilot run in two sequential stages. The first settles the building block: base depth is swept standalone, since the base is trained before any gate exists and its optimum cannot depend on one, while expert depth is swept at matched total capacity so that width adjusts with depth. Because the weight concentration of a gate determines how much data each expert effectively trains on, and the candidate gates differ in that concentration, expert depth may not be optimal at the same value for every gate. Fixing a depth risks a specification that suits some mechanisms and handicaps others, so every gate is run at every candidate depth and the complete grid is reported, in the manner of the architecture ladders already standard in this literature but with gates as the second dimension. Total mixture capacity is held fixed across the grid, so that moving along the depth axis changes the shape in which a constant parameter budget is arranged, not the budget itself. Nothing is selected: the table is the result. It exhibits directly whether the ordering of gates is stable across depths, which is the robustness claim the comparison rests on, and whether any mechanism is favoured by a particular depth, which is the interaction that fixing a depth would conceal. A single cell of that grid is nominated in advance as the primary configuration for significance testing. The second stage settles the way the blocks are combined, comparing the residual construction against a standard mixture and varying the initialisation and the strength of the correction penalty. Neither stage can be settled by citation: no study ablates expert depth inside a mixture for this task, and two of the construction configurations do not appear in the published record. Nor is the pilot expected to separate configurations on accuracy, since the largest study of depth in this literature cannot do so on its own data [27]; the decision rules are therefore fixed in advance on training stability across seeds and on whether a configuration leaves an expert contribution large enough to analyse. Run the comparison under walk-forward evaluation with purged splits [30], repeating each configuration over many seeds and reporting distributions, not point estimates, with the number of regimes fixed across mechanisms and swept afterwards. Close with diagnostics, which carry more weight here than usual because freezing the base isolates the correction term without guaranteeing what it contains. The aggregate correction is therefore decomposed into a gate-independent component, which would indicate the experts are patching an underfitted base instead of specialising, and a gate-conditional component; the fitted gate weights are replaced at inference by uniform and by permuted weights, so that the loss in performance measures the gate's contribution directly; the dispersion of corrections across experts is reported, since a balanced gate over near-identical experts would leave the routing decorative; and the correction is examined for timing, for correspondence with external classifications such as recession dates and volatility quantiles, and for performance decomposed by market condition.

## Feasibility analysis

The design is deliberately small. Because a model observation is a characteristic vector, not a price history, the experts are compact perceptrons, not sequence models, so the full set of runs is within reach of available hardware; the same design with Transformer experts would not be. The components exist as libraries, and the two heaviest candidates considered, explicit-duration models and non-parametric selection of the number of states, were excluded in favour of cheaper approximations. An existing codebase supplies the data pipeline, baselines and backtesting. Two matters remain open. Database access is unconfirmed, with public price data and a reduced characteristic set as the fallback, which narrows comparability but leaves the internal comparison intact. And the computational cost of the design has to be measured, not assumed: running every gate at every candidate depth multiplies the number of training runs several times over relative to a single fixed architecture, so whether the full grid fits the hardware and time available must be measured before the design is fixed. If it does not, the depth axis or the seed count used for the descriptive cells can be reduced without altering what the comparison tests.
